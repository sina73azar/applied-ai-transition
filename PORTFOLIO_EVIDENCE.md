# Portfolio Evidence Template

Copy this template into each project's documentation.

## Problem

State the user, the expensive or unreliable behavior, and the measurable target.

## Constraints

Record data availability, privacy, infrastructure, latency, cost, language, and
access limitations.

## Baseline

Describe the simplest working approach and report its measurements before
introducing a more complex model or architecture.

## Design and Personal Ownership

- Decisions I made:
- Components I implemented:
- Components generated with assistance and then reviewed:
- Existing libraries or templates reused:

## Evaluation

Include dataset/version, split strategy, metrics, exact run command, result
table, failure slices, and limitations. For AI answers, separate retrieval
quality from answer quality.

## Operations

Include deployment shape, latency percentiles, resource usage, observability,
failure behavior, privacy controls, and recovery procedure.

## Result

Compare against the baseline. Do not claim an improvement without a repeatable
measurement.

## Retrospective

Explain one failed approach, one tradeoff, and the next experiment.
