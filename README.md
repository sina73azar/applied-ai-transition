# Applied AI Career Transition

This directory turns the career roadmap into weekly work, measurable gates, and
portfolio evidence. It is intentionally separate from the CM Context Assistant
runtime.

## Start Here

1. Create the local environment:

   ```bash
   python3 -m venv .venv
   .venv/bin/pip install pytest
   ```

2. Read [ROADMAP.md](ROADMAP.md).
3. Begin the eight-week [Python Foundations](python_foundations/README.md)
   program on Monday, August 3, 2026.
4. Update [PROGRESS.md](PROGRESS.md) every Sunday.
5. Record all assistance in [AI_USAGE_LOG.md](AI_USAGE_LOG.md).
6. Collect measurable project evidence with
   [PORTFOLIO_EVIDENCE.md](PORTFOLIO_EVIDENCE.md).

## Operating Rules

- Budget 8-10 focused hours each week.
- Work for 45-60 minutes before asking an AI assistant for implementation help.
- Prefer hints, review, debugging questions, and test feedback over generated
  solutions.
- Do not mark work complete unless you can explain it without opening the code.
- Keep employer code, documents, vector databases, credentials, and internal
  metadata out of public projects.
- Missed weeks move forward; they do not create double-work weeks.

## Weekly Definition of Done

A week is complete only when:

- its required study and implementation work is finished;
- relevant automated checks pass;
- one debugging or design lesson is recorded;
- the code can be explained from memory;
- the progress and AI-usage logs are updated.
